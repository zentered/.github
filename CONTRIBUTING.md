# Contributing

Thanks for your interest in Zentered projects.

## Before you start

- Check the open issues and pull requests for duplicates.
- For a larger change, open an issue first so we can agree on the approach.

## Pull requests

1. Fork the repository and create a branch from `main`.
2. Keep each pull request to one change.
3. Run the project's tests and linter before you open the pull request.
4. Use a commit message in the form `type(scope): description`, in lowercase and imperative mood.
5. Open the pull request as a draft until it is ready for review.

## Security issues

Do not report security issues in a pull request or issue. See [SECURITY.md](SECURITY.md).
